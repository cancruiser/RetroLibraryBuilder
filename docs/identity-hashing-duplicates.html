Evidence-based identity

Same name does not mean same game.

RLB's architecture separates filenames from identity. Hashes, ROM headers, catalog evidence, source context and variant rules can all contribute to deciding what a file actually represents.

Important Beta distinction: RLB already contains advanced hashing, DAT, header, variant and canonical-selection services, but exact behavior is still being unified across all active import paths. The website does not claim every source form has identical canonical-identification depth yet.

Four hashes, different jobs

SHA-256

Full-file fingerprint used for strong byte-level duplicate identity.

SHA-1

Common catalog/DAT identity evidence.

MD5

Additional catalog/DAT matching evidence.

CRC32

Widely used ROM-catalog checksum evidence.

Header-aware identification

Some ROM formats contain copier or platform headers that should not change the identity of the underlying game data. RLB includes normalization for cases such as iNES, SNES copier headers and Atari 7800 A78 headers so catalog matching can reason about the content rather than blindly hashing every wrapper byte.

Canonical identity and variants

Two files can be related without being interchangeable. Region, revision, dump quality, container format, naming and release variant may all matter. RLB's canonical model is designed to preserve observed evidence, select a preferred physical representative only when evidence is strong enough, and keep the losing source observations traceable.

Duplicates are a storage decision

RLB's design does not treat duplicate collapse as permission to erase source history or curate a user's collection. It is a storage decision made only when evidence supports that two physical representations refer to the same playable release. Relationship members must remain intact.

Why filenames are not enough

Renamed ROMs, alternate containers, regional naming, archive names and retail-card folder layouts can all be misleading. RLB therefore treats filenames and paths as evidence, not absolute truth.
