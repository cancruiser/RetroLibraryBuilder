SIMPLE WORKFLOW

Connect → Identify → Protect → Build

RLB may perform a lot of technical work underneath, but most users only need this mental model.

ConnectInsert original media or choose the content source you want to work with.
IdentifyRLB gathers evidence about the device, firmware, storage and content.
ProtectOriginal content is accounted for and verified before destructive work is allowed.
BuildWhen the target is safe, RLB prepares replacement media using the correct firmware-specific process.

WHY RLB

More than an SD-card copier

Retro devices can hide important boot assets, configuration, BIOS, saves, artwork and hardware-specific files across several partitions. RLB tries to understand the device before deciding what should be preserved or rebuilt.

◎
