Managed Library status

See what needs attention without manually auditing the Library.

Library Health summarizes actionable problems and routes the user to the correct repair workspace instead of turning status into another editing screen.

Recommended actions

Library Health surfaces issues such as missing artwork, titles with multiple preserved variants, unmatched media and verification work that deserves attention.

Open the right repair workflow

Each issue points back to the workspace that owns the repair. Missing artwork and variant review return to Library Explorer, unmatched media opens Media Explorer, and verification work returns to Import Studio.

Library inventory

Live managed-Library totals provide context for the health indicators so a problem count can be understood relative to the Library it belongs to.

Artwork coverage

Artwork coverage is represented as a measurable Library-health concern rather than being mixed into game identity. Media can therefore be improved without changing the underlying canonical game records.
