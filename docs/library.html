Managed Library

Browse the Library RLB actually manages.

Library Explorer presents the managed systems, canonical games, ROM variants, media, BIOS, saves and configurations that RLB has established through its Library workflows.

LIBRARY EXPLORER — ACTUAL RLB INTERFACE
Managed Library, not source folders: Library Explorer shows the content RLB manages after import and verification workflows. It is not simply a file browser pointed at the original source.

1. What Library Explorer is for

Library Explorer is the main browsing view for the RLB managed Library. It brings together systems, canonical games and linked managed content in one place while still exposing platform-level folders when filesystem inspection is needed.

The workspace is designed to browse the real managed Library with safely paged artwork rather than loading the entire collection into the UI at once.

2. The Library snapshot separates content lanes

The summary row across the top reports the major managed Library lanes independently.

GAMESGamesManaged game records across Library platforms.
MEDIAMediaArtwork and support media linked to Library content.
BIOSBIOSManaged BIOS/support files tracked separately from games.
SAVESSavesManaged save content known to the Library.
CONFIGSConfigsManaged configuration content.
SIZELibrary SizeTotal size of the managed Library across its lanes.

3. Library health summarizes the collection

The Library health strip gives a quick collection-level summary rather than requiring the user to inspect each platform separately.

TITLESCanonical title countThe number of managed titles represented across the Library.
ARTWORKArtwork coverageThe percentage of titles currently represented by managed artwork.
MISSINGMissing artworkThe number of titles still lacking the required artwork coverage.

The Details button provides a path into more information when the high-level health summary needs investigation.

4. Browse the Library by platform

The left-hand Platforms pane is the primary navigation for Library Explorer. It supports sorting and platform search, and each platform entry reports the amount of managed game and media content associated with that system.

5. Canonical games and ROM variants are different counts

The selected-platform summary explicitly reports canonical games and ROM variants separately.

CANONICAL GAMEThe Library titleThe game identity RLB uses as the main managed record for browsing and linked content.
↔
ROM VARIANTPlayable representationOne or more ROM representations can be associated with a canonical title without turning each variant into a separate browsing identity.

This distinction is what allows RLB to present a clean game library while still retaining the underlying playable-content relationships.

6. A selected platform shows more than games

The platform header also reports the linked content that belongs to the selected system.

↓SavesManaged save content associated with the selected platform.

7. Search, sort and filter without leaving the platform

Library Explorer provides a platform-local game search along with sort and filter controls. This allows the user to narrow a large platform without losing the current system context.

The View control determines how the game records are presented. In the screenshot, the view is set to Box Art.

8. Artwork is safely paged

The Library Explorer subtitle calls out safely paged artwork, and the content area shows explicit Previous and Next controls.

The status line also notes that thumbnails load one at a time. This matters for very large libraries because browsing should not require loading tens of thousands of images into memory at once.

1Page the game recordsOnly a manageable set of titles is shown at one time.

9. Game cards combine identity and managed media

Each visible game card represents the canonical title and shows the preferred artwork for browsing. The card also reports media information associated with that game.

This is the same canonical-media relationship exposed in greater detail by Media Explorer.

10. Platform and Library folders remain accessible

Open Platform Folder provides filesystem access to the selected platform when direct inspection is needed.

Open Library Folder does the same at the managed-Library level. These are inspection conveniences; the Library Explorer remains the structured view that explains how RLB understands the content.

11. Refresh updates the current Library view

The Refresh action reloads the workspace after Library content, artwork or related managed data has changed. The page also reports when the Library Explorer view was last updated.

12. Import, Review, Library and Media form one workflow

These workspaces are different views of the same managed-content lifecycle rather than separate utilities.

IMPORTDiscover and approveAnalyze sources and copy approved content into managed Library lanes.
→

→
LIBRARYBrowse managed contentExplore systems, canonical games and linked content after import.
→

Library principles

✓Keep games, media, BIOS, saves and configs as distinct managed lanes
✓Browse by canonical game while retaining ROM-variant relationships
✓Expose Library health instead of hiding incomplete artwork coverage
✓Page large collections and load artwork progressively
✓Keep filesystem access available without reducing the Library to a folder browser

What comes next?

The managed Library is one half of RLB’s reusable foundation. The other is Knowledge: the device, firmware, DTB and compatibility information that helps RLB understand what it is preserving and what can later be deployed.
