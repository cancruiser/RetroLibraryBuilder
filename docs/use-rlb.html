THE SIMPLE RLB MODEL

Connect → Identify → Protect → Build

RLB may do a great deal of technical work underneath, but this is the basic path most people need to understand.

ConnectInsert the device media or select the content source you want RLB to work with.
IdentifyRLB gathers evidence about the device, firmware, storage and content.
ProtectImportant original content is accounted for and verified before destructive work is allowed.
BuildWhen the target is safe, RLB can prepare replacement media using the correct firmware-specific workflow.
