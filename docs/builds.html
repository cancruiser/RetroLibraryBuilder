Current build status

Accepted SBC builds. Physically tested.

Support is accepted only after real-device validation. These pages document the current SBC firmware tracks that have passed physical deployment testing on Raspberry Pi 3B+ hardware. Accepted tracks are frozen unless later work reveals a regression.

Scope: Batocera, Recalbox, RetroPie and Lakka are the accepted SBC baseline. Handheld deployment work follows this phase.
Acceptance model
Physical pass required
1
Acquire and write firmwarePrepare the target media using firmware-specific rules.
2
Provision the deviceHandle first-boot, storage expansion, network and identity where supported.
3
Deploy full contentROMs, BIOS, artwork/media and relevant user/configuration data.
4
Verify and finalizeDevice-side verification plus frontend refresh/finalization.
