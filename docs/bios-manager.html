Managed firmware support

BIOS files are managed as first-class support assets.

BIOS Manager keeps BIOS, Kickstarts, boot ROMs, IPLs, system ROMs and emulator-support firmware separate from game content while preserving the knowledge needed to identify and deploy them correctly.

BIOS families

Managed BIOS files are grouped into recognizable families so related revisions can be reviewed together rather than presented as one undifferentiated file list.

Acquire and analyze

A BIOS collection can be analyzed before import. Source material remains read-only until the user chooses Import, allowing RLB to calculate signatures and determine what it recognizes without modifying the source.

Verification knowledge

BIOS Manager can use canonical BIOS identity and multi-hash knowledge to distinguish known support files and valid revisions. This is important because a firmware build should receive the BIOS required by its selected systems, not the entire BIOS library.

Deployment integration

Deployment selects managed BIOS through the reviewed system selection and firmware profile. Accepted SBC deployment tracks use firmware-appropriate BIOS destinations while preserving the user's authoritative managed Library as the source.

Scope

BIOS Manager is not a ROM download service and does not treat support firmware as artwork. It is a managed support lane with its own identity, verification and deployment rules.
