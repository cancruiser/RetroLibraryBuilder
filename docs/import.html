Library workflow

Analyze first. Import only what was approved.

Import Studio is RLB’s controlled path for bringing games, BIOS, media, saves and configuration into managed Library lanes without changing the original source.

IMPORT STUDIO — ACTUAL RLB INTERFACE
Source-safe workflow: Import Studio analyzes selected sources without changing them. RLB’s import workflow copies approved content into managed destinations; originals are not renamed, moved or deleted.

1. What Import Studio is for

Import Studio is the entry point for bringing content into the RLB managed Library through an explicit analyze, review, import and verification process.

The screen describes the supported content lanes as games, media, BIOS, saves and configurations. The selected Import mode controls which approved lanes are imported after analysis.

▣GamesPlayable content intended for managed Library organization and later reuse.
◫BIOSSystem firmware/support files tracked separately from game content.
▰MediaArtwork and related media assets discovered for managed media lanes.
↓SavesUser save content identified during source analysis.
⚙ConfigurationConfiguration content that belongs in an approved managed lane.

2. The five-stage workflow

The left side of Import Studio shows the workflow explicitly:

1Select SourcesAdd the folders or archive collections RLB should inventory.
2Analyze SourcesInventory the complete source and determine platforms, targets and exclusions.
3Review ImportInspect exactly what RLB discovered before approving an import.
4Import to LibraryCopy only the content approved by the reviewed analysis into managed Library lanes.
5Verify & ReportVerify the resulting import and produce the completed import report.

Only one approved stage feeds the next. Later stages remain locked until the required earlier state exists.

3. Add the sources you want to analyze

The Source Actions pane provides two starting points:

＋Add Source FolderAdd a folder, removable drive or network location that RLB should inspect.
▦Add Archive CollectionAdd a collection represented by archive files such as ZIP-based sets.

Import Studio groups selected sources into Collections and shows the platform names detected during analysis.

4. Choose the Import mode

The Import mode controls which approved content lanes will be imported. In the example screen, the selected mode is Complete Library.

Import mode does not change the source-analysis principle: RLB still inventories the complete source so the review can show what was discovered before approved content is copied.

5. Analyze Sources before importing anything

Once at least one source has been added, Analyze Sources becomes the next workflow step. Analysis inventories the source and produces the information required for Review Import.

SOURCE ANALYSIS CAN PRODUCE
✓Source roots
✓ROM and BIOS targets
✓Media and asset lanes
✓Save and config lanes
✓Infrastructure exclusions
✓Traversal diagnostics
Why analyze first? RLB needs a complete picture of the selected sources before the user can meaningfully review what should enter the managed Library.

6. Review Import is the approval boundary

The screen states that Review Import presents exactly what was discovered before an approved import can begin.

This is an important separation. Analysis discovers and classifies; Review Import gives the user a chance to inspect the proposed result; only then can the approved import proceed.

7. Import to Library copies; it does not reorganize the source

The Import Studio guidance is explicit: source files are copied only and are never renamed, moved or deleted.

✓
Managed destinationRLB can establish approved Library content without changing the source that was analyzed.
×
No destructive cleanupImport is not permission to rename, move or delete the user’s original source content.

8. Verify & Report closes the workflow

After the approved import completes, the final stage is Verify & Report. Verification and the completed import report provide the durable result consumed by the Library workflow.

The Import Studio itself notes that Verify & Report consumes the completed import report, keeping the workflow connected from source selection through final verification.

9. Why so many actions are disabled at first

In the initial screen, Analyze Sources, Review Import and other actions are disabled because there is no valid source state yet. This is intentional.

Import Studio is designed so that stages unlock in order rather than letting a user jump directly to an import without an analyzed and reviewed plan.

10. Reset Managed Library is different from clearing sources

The Actions pane contains both source/session actions and a separate Reset Managed Library action. Those should not be confused.

Clear Sources relates to the current source selection/session. Reset Managed Library is a separate Library-level action and should be treated accordingly.

Be deliberate with Library-level actions. Do not use Reset Managed Library as a substitute for clearing or restarting an import session.

What comes after Import?

Import is only one part of Library management. Content that needs human attention or classification can surface through Review, while media assets are managed through the Media workspace. The Library workspace shows the resulting managed collection.
