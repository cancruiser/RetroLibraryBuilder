Home / Home Dashboard
Operational status

One place to see what RLB knows and what needs attention.

The Home Dashboard is the status surface for preserved ecosystems, Library health, recommendations, recent activity, storage and long-running work.

Preserved ecosystems

The dashboard surfaces preserved devices and ecosystems without forcing the user to reopen individual preservation reports. Device identity, firmware context, preservation state and available recovery evidence can be seen at a glance.

Library snapshot

Library summary cards expose the major managed-content counts and storage footprint, including games, media assets, BIOS, platforms, devices and Library size. The purpose is operational visibility rather than a second Library browser.

Recommendations

RLB can surface actionable knowledge such as firmware evidence, BIOS coverage, media coverage and device-profile information. Priority indicators help distinguish items that deserve attention from lower-priority housekeeping.

Recent activity

Knowledge diagnostics, provider validation and other completed operations are visible in the activity feed so significant backend work is not invisible to the user.

Storage

The dashboard summarizes managed storage areas and preserved-library usage. Detailed content management remains in the appropriate workspace; the Home screen answers the simpler question: how much is stored and where is attention needed?

Background operations

Long-running user and knowledge work is represented through a live task area. RLB's accepted UX direction is that expensive work should remain visible and should not make the application appear frozen or hide whether an operation is still active.

Durable work matters. Preservation and other long-running operations maintain state outside the immediate screen so interruption, resume and final verification can be reasoned about explicitly.

Quick actions and continue working

The dashboard provides direct routes into the jobs users perform most often, such as preserving a device, importing content, checking readiness, opening Knowledge, reviewing missing media and planning a deployment.
