RLB workspaces

The application, one workspace at a time.

RLB separates status, managed content, device intelligence, preservation readiness and deployment so each screen can answer a specific question without turning the application into one giant workflow.

STATUS
Home DashboardPreserved ecosystems, Library snapshot, recommendations, recent activity, storage and background tasks.
MANAGED CONTENT
Import StudioAnalyze sources and approve what enters the managed Library.→Review CenterResolve only the exceptions that need an explicit decision.→Library ExplorerBrowse managed games and content RLB established.↔Media ExplorerManage preferred covers and linked media assets.
DEVICE SAFETY
Device InspectorUnderstand the actual device and its preservation state.→Device ReadinessDecide whether knowledge is strong enough for any deployable target.→DeploymentBuild validated targets using firmware-specific provisioning, content routing, verification and frontend finalization.
