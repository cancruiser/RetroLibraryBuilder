¿Nuevo en RLB?

Si tienes una consola portátil, un SBC o una tarjeta SD original y no sabes por dónde empezar, comienza por la protección. RLB está diseñado para comprender y proteger el original antes de pedirte que lo reconstruyas o cambies.

EL MODELO SIMPLE DE RLB

Conectar → Identificar → Proteger → Construir

RLB puede realizar una gran cantidad de trabajo técnico por debajo, pero este es el camino básico que la mayoría de las personas necesita entender.

ConectarInserta el medio del dispositivo o selecciona la fuente de contenido con la que quieres que trabaje RLB.
IdentificarRLB recopila pruebas sobre el dispositivo, firmware, almacenamiento y contenido.
ProtegerEl contenido original importante se contabiliza y verifica antes de permitir trabajo destructivo.
ConstruirCuando el destino es seguro, RLB puede preparar un medio de reemplazo usando el flujo correcto para ese firmware.

¿Quieres saber qué hace RLB por debajo?

La rama técnica explica capacidades, espacios de trabajo, reglas de preservación, preparación de dispositivos, conocimiento y versiones aceptadas.
