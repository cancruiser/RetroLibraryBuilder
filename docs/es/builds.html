Estado actual de versiones

Versiones SBC aceptadas. Probadas físicamente.

El soporte solo se acepta después de validación en un dispositivo real. Estas páginas documentan las rutas actuales de firmware SBC que han superado pruebas físicas de despliegue en hardware Raspberry Pi 3B+. Las rutas aceptadas quedan congeladas salvo que trabajo posterior revele una regresión.

Alcance: Batocera, Recalbox, RetroPie y Lakka forman la base SBC aceptada. El trabajo de despliegue para portátiles sigue a esta fase.
Modelo de aceptación
Se requiere prueba física
1
Adquirir y escribir firmwarePreparar el medio de destino usando reglas específicas del firmware.
2
Aprovisionar el dispositivoGestionar primer arranque, expansión de almacenamiento, red e identidad cuando sean compatibles.
3
Desplegar todo el contenidoROM, BIOS, ilustraciones/medios y datos relevantes de usuario/configuración.
4
Verificar y finalizarVerificación en el dispositivo más actualización/finalización del frontend.
BASE SBC ACEPTADA
✓

Batocera — Aceptado / Congelado

La escritura del firmware, expansión de userdata, Wi-Fi del primer arranque, aprovisionamiento, identidad, despliegue de contenido, verificación SHA-256 en el dispositivo, actualización de EmulationStation y LocalArt han superado las pruebas físicas.

Ver aceptación de Batocera →
✓

Recalbox — Aceptado / Congelado

El despliegue nativo, la verificación, el manejo del frontend y la reparación de ilustraciones alcanzaron una finalización terminal estable sin repetir copias o verificaciones ya completadas.

Ver aceptación de Recalbox →
✓

RetroPie — Aceptado / Congelado

El despliegue nuevo, Wi-Fi, restauración del perfil de controlador, colocación nativa de ROM, verificación SHA-256, finalización de gamelist/ilustraciones y finalización estable superaron la prueba física.

Ver aceptación de RetroPie →
✓

Lakka — Aceptado / Congelado

La restauración de punto de control verificado, generación de listas RetroArch, reutilización de miniaturas, finalización del frontend y 100 % de finalización total superaron la validación física.

Ver aceptación de Lakka →
